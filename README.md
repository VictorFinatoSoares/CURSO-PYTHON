# Curso de Python 3

Curso de Python 3 organizado em **mundos**. Cada mundo reúne um conjunto de tópicos relacionados e é dividido em duas partes:

- 📘 **Aulas** — o conteúdo teórico do assunto, explicando os conceitos.
- 💻 **Exercícios** — desafios práticos para fixar o que foi aprendido em cada aula.

A ideia é avançar mundo por mundo, sempre estudando a teoria antes de partir para a prática.

## 🌎 Mundos

| Mundo | Tema                    | Status |
| ----- | ----------------------- | ------ |
| 01    | Fundamentos             | ☑️     |
| 02    | Estruturas de controle  | ☑️     |
| 03    | Estruturas Compostas    | ⬜     |
| 04    | POO (Objetos e Classes) | ⬜     |

> Atualize a tabela acima conforme os mundos forem adicionados/concluídos.

## 📁 Estrutura de pastas

```
Curso_Em_Video/
├── Mundo 1/
│   ├── Aulas (Teoria)/
│   └── Exercicios/
├── Mundo 02/
│   ├── Aulas (Teoria)/
│   └── Exercicios/
└── ...
```

## ▶️ Como usar

1. Escolha um mundo para estudar.
2. Leia o material da pasta `Aulas (Teoria)/`.
3. Resolva os desafios da pasta `Exercicios/` correspondente.
4. Avance para o próximo mundo.

## 🛠️ Pré-requisitos

- [Python 3](https://www.python.org/downloads/) instalado
- Um editor de código (recomendado: [VS Code](https://code.visualstudio.com/))
