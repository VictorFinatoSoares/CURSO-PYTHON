# Curso de Python 3

Repositório pessoal para estudo e prática de Python, organizado por mundos e dividido entre teoria e exercícios.

## Visão geral

Este projeto acompanha o aprendizado do curso de Python, seguindo uma estrutura progressiva:

- 📘 `estudos/` ou `estudo/`: arquivos de teoria e exemplos práticos.
- 💻 `exercicios/`: desafios para consolidar o conteúdo aprendido.
- 🌍 Organização por níveis: `mundo_1`, `mundo_2`, `mundo_3`.

A proposta é estudar um mundo por vez, entender os conceitos e depois resolver os exercícios correspondentes.

## 🧠 Fluxo de estudo

1. Acesse a pasta do mundo atual.
2. Leia os arquivos de estudo (`estudos/` ou `estudo/`).
3. Resolva os exercícios da pasta `exercicios/`.
4. Revise os conceitos até dominar o conteúdo antes de avançar.

## ▶️ Como executar

Pré-requisitos:

- [Python 3](https://www.python.org/downloads/) instalado
- [uv](https://docs.astral.sh/uv/) (opcional, mas recomendado para gerenciar o projeto)

Exemplo de uso:

```bash
python --version
uv run python --version
```
